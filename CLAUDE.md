# Instructions for AI assistants

Read `readme.md` first, in particular the section "If you are an AI
working on this project". Then read `docs/handoff.md`, which says where
the work stands and what has been decided.

The rule that must not be missed: `docs/whitetail-feedback.md` is read
before every piece of work and updated as part of it. Recording what is
wrong or awkward in Whitetail is half the purpose of this project.
