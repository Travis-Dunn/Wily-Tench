Font sources for Wily Tench
===========================

These are the fonts the game's text is made from. FontTool (under
src/test) converts them into the .fnt files in src/main/resources/fonts
that the game actually loads; see the "Fonts" section of the main readme.

helvR08.bdf, helvB08.bdf, helvB12.bdf
-------------------------------------

Helvetica 8 pixel regular, 8 pixel bold, and 12 pixel bold, from the X.Org
"font-adobe-75dpi" bitmap font collection, ISO 8859-1 encoding. Converted
from the PCF files in Debian's xfonts-75dpi package to BDF with pcf2bdf;
the glyphs are unchanged.
